# 안전 수칙

- 모델이 만든 코드와 데이터셋의 취약 코드는 Docker 컨테이너 안에서만 실행합니다.
  - 컨테이너는 `--network none`으로 네트워크를 끊습니다.
  - 메모리 상한을 두고, 시험마다 새 임시 폴더를 씁니다.
- Rust 크레이트를 받는 단계만 네트워크를 씁니다. 빌드와 실행은 네트워크 없이 합니다.
- 효과 시험은 실제 피해를 주지 않는 표식 하나만 남기는 입력만 씁니다. 그 입력 틀은 오용될 수 있어 공개하지 않습니다.
- API 키는 환경 변수로만 받습니다. 저장소에 키나 `.env`를 커밋하지 않습니다.
- 모델이 지어낸 라이브러리 이름은 개수와 유형만 보고합니다. 이름 목록을 공개하면 누군가 그 이름으로 악성 꾸러미를 먼저 올릴 수 있기 때문입니다.
