# 개발용 결과 (탐색용, 확증 결과 아님)

## 어떻게 돌린 결과인가
- **모델:** Claude Haiku 5.5 하나입니다.
  - API로 부르지 않았습니다. 코딩 도구(Claude Code)의 하위 에이전트로 돌려, 요청과 답을 파일로 주고받았습니다. 그래서 temperature와 seed는 정하거나 기록할 수 없었습니다.
  - 실행 기록의 모델 칸에는 코드의 기본 이름표 "claude-code-subagent(sonnet)"이 그대로 남아 있습니다. 하지만 실제로 돌린 모델은 Haiku 5.5입니다. 이것은 당시 실행 메모에 적어 둔 것이고, 이름표를 고치지 않은 것은 기록의 한계입니다.
- **표본:** 확증용과 겹치지 않는 개발용 69항목입니다.
- **횟수:** 번역은 항목마다 1개, 실행은 조건마다 1번입니다.
- **쓴 곳:** 절차와 비교 조건을 정하는 데만 썼고, 확증 결론에는 쓰지 않습니다.

## 읽을 때 주의할 점
- 숫자는 데이터셋 보안 시험의 판정입니다. 개발용 실행에서는 효과 시험을 돌리지 않았으므로, 실제 공격 효과를 센 수가 아닙니다.
- 값을 기대한 보안 시험에서 오류를 낸 경우("값 대신 오류")도 뚫림으로 셉니다. 자기 비판 반복의 숫자는 이것의 영향을 크게 받습니다.
- 출력이 4,000자를 넘어 잘린 번역 3개는 세부 판정을 할 수 없습니다.
- 기능 시험에서 떨어진 취약판 번역 5개는 모두 약한 암호 유형입니다.
- 위 판정 문제는 확증 실행 전에 도구를 고쳐 반영합니다.
- 다시 세는 스크립트는 `dataset_pilot/dev_summary_table.py`와 `dataset_pilot/dev_judgment_recount.py`입니다. 문서 안의 원래 파일 이름은 이렇게 바뀌었습니다.
  - `판정근거_재집계.md` → `judgment_recount_ko.md`
  - `판정근거_항목별.csv` → `judgment_recount_per_item.csv`
